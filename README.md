# 🚗 Suzuki Sales Intelligence Dashboard

## 📌 Project Overview
This project analyzes automotive sales data to uncover trends, optimize dealership performance, and support data-driven decision-making for a company like Suzuki. The goal was to simulate a real-world business intelligence scenario where sales leaders require actionable insights.

---

## 🛠 Tech Stack
- Python
- Pandas
- Matplotlib

---

## 📊 Key Insights
- Identified top-performing regions contributing to over 60% of total sales.
- Seasonal trends showed peak sales during Q2 and Q4, indicating strong promotional impact.
- Certain car models consistently underperformed, highlighting inventory optimization opportunities.
- Dealer-level performance analysis revealed significant variance in conversion rates.
