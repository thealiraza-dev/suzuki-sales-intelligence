# Suzuki Sales Intelligence – Business Analytics System

## Overview
This project simulates a real-world automotive sales intelligence system designed to help businesses analyze sales performance, regional trends, and economic impact (inflation).

It demonstrates how data analytics can support **strategic business decisions** in the automotive industry.

---

## Business Problem
Companies struggle to:
- Understand regional sales performance
- Measure impact of inflation on sales
- Identify best-performing models and cities
- Make data-driven pricing and marketing decisions

---

## Solution
Built a **Business Intelligence system** that:
- Analyzes sales trends across models and cities
- Measures inflation impact on sales performance
- Provides KPI-based executive dashboards
- Generates actionable business insights

---

## Tech Stack
- Python
- Pandas
- Matplotlib
- Streamlit
- Git & GitHub

---

## Key Features

### Sales Performance Analysis
- Model-wise sales comparison (Alto, Swift, Cultus)
- City-wise sales distribution

### Economic Impact Analysis
- Inflation vs Sales correlation study
- Pricing sensitivity insights

### Business Intelligence Dashboard
- KPI metrics (Total Sales, Avg Sales, Top Model, Top City)
- Interactive filtering system
- Real-time visualization

---

## Key Business Insights
- Identifies top-performing vehicle models
- Highlights high-revenue cities
- Measures inflation impact on demand
- Supports strategic marketing decisions
